# gestion-employers
# Application de gestion des employés

## Présentation

Cette application console permet à une entreprise de gérer ses employés
et ses départements.

## Objectifs

- Appliquer la programmation orientée objet en Python.
- Manipuler les fichiers JSON.
- Gérer les exceptions.
- Utiliser Git et GitHub.
- Travailler en équipe avec des branches et des Pull Requests.

## Fonctionnalités

- Ajouter, modifier et supprimer un employé.
- Rechercher un employé par matricule.
- Afficher tous les employés.
- Ajouter, modifier et supprimer un département.
- Affecter un employé à un département.
- Afficher des statistiques salariales.
- Sauvegarder et recharger automatiquement les données.

## Technologies utilisées

- Python 3
- Git
- GitHub
- Fichiers JSON

## Installation

Cloner le dépôt :

```bash
git clone https://github.com/UTILISATEUR/gestion-employes.git
cd gestion-employes
```

Lancer l'application :

```bash
python3 main.py
```

## Structure

- `main.py` : menu principal.
- `employe.py` : classe Employe.
- `departement.py` : classe Departement.
- `gestion_employes.py` : gestion des employés.
- `gestion_departements.py` : gestion des départements.
- `utils.py` : lecture et écriture JSON.
